# 开发预算v1：来自同一个实测点

参照：**FHReg-GUSO／512主设置**。该点属于本轮公共仿射协议实测非支配集合。

| 项目 | 预算／验收目标 |
|---|---:|
| SR@5px底线 | ≥65.4412% |
| SR@3px底线 | ≥43.5924% |
| 端到端中位延迟 | <57.452ms |
| 峰值分配显存 | <1133.86MiB |
| 误差参考（中位/P90） | 3.448/12.116px |
| 求解失败参考 | 21/952 |

四项主门槛全部来自这一个参照点。延迟和显存要求更低，同时SR@3/5达到其参照水平；误差尾部、求解失败和极端失败必须单独报告，不能删掉坏例达标。没有将FH的精度、T05的延迟与另一个方法的显存拼起来。

当前T05全量SR@5=54.6218%，距目标10.8193个百分点；其延迟9.787ms、显存53.90MiB是当前起点，不能假定加模块仍维持这些成本。本预算是后续开发的研究验收目标，不是已达到的结果或可行性承诺。保持本轮固定验证、输入/拟合边界、独占卡和无hook测量；测试集继续不用于选结构或调阈值。

本轮没有启动任何新训练。FH512主配置与256敏感性对照保持事前登记，不用差异倒推更有利的阈值。GDROS原生稠密协议另列，不能用其时间替换公共仿射精度成本。
